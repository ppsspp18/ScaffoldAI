How to use:
1. Ask the LLM for project code.
2. Ask the LLM again using the scaffold prompt to return only the file/folder JSON.
3. Paste the JSON here and click Build Scaffold.
4. Open each file and paste the code manually — or click 📥 Load Project from Folder to pull in an existing local project automatically.
5. Save the project straight to a folder on your PC, or export it as JSON/ZIP.

2) Project Workspace

Load Project from Folder reads an existing project straight from your PC — it builds the scaffold structure and fills in every file's code automatically, no JSON pasting needed. Apply Changes to Folder then writes back only the files you've created, edited, or deleted since the last sync — no full re-download needed.
