💡 How to use ScaffoldAI
  1. 1 Click Load Project from Folder and pick your project's folder on disk.
  2. 2 Browse the Project Tree below. Check the files or folders you want.
  3. 3 Copy Structure copies just the folder/file tree as text — great for giving an AI context on layout.
  4. 4 Copy Files as Text copies the checked files' full contents, each labeled with its path — ready to paste into any AI chat.
