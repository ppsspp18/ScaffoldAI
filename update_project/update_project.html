💡 How to use ScaffoldAI
  1. 1 Click Load Project from Folder and pick your project's folder on disk (or load a saved project JSON instead).
  2. 2 Use Ask AI About Your Project below to get AI help with changes, or copy files as plain text.
  3. 3 Open any file in the workspace to view or edit its content.
  4. 4 Click Apply Changes to Folder to write your edits straight back to disk.

2) Ask AI About Your Project

Select files → Ask → Copy → Apply JSON

Tick the files you want the AI to see (or just mention them as @filename in your message and they'll be picked up automatically), describe what you want, then copy the generated prompt into ChatGPT / Claude / Gemini. Once you're happy with its answer, send it the Sync Prompt below so it returns a structured JSON of every file it changed — paste that back here and ScaffoldAI will update your project.

Load a project first to select files.
