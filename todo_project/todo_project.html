💡 How to use the To-Do Plan workflow
  1. 1 Click Load Project from Folder and pick your project's folder on disk (or load a saved project JSON instead).
  2. 2 Describe the big task, click Generate Plan Prompt, and paste it into ChatGPT / Claude / Gemini. It will reply with a JSON to-do list — no code yet.
  3. 3 Paste that JSON into Load Plan. Each step appears as a checklist item with its own Copy Step Prompt button, pre-loaded with the plan, progress so far, and the relevant files' current content.
  4. 4 Paste a step's prompt into a fresh AI chat, get back code, then use the Sync Prompt + change list below to apply it to your project. Tick the step's checkbox once it's done.
  5. 5 Repeat for each step — later step prompts automatically include whatever earlier steps changed.
