  1. 1 Ask AI to write complete project code.
  2. 2 Ask AI again using the scaffold prompt to return only the file/folder JSON.
  3. 3 Paste the JSON here and click Build Scaffold.
  4. 4 Open each file and paste the code manually.
  5. 5 Save the project straight to a folder on your PC, or download it as a ZIP.
